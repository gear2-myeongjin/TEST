# TVPaint Auto Tools

TVPaint 11 (11.5 이상) 보조 도구. 선택한 애니메이션 레이어에 대해 두 가지 작업을 합니다.

**Crop**: 모든 프레임의 실제 그림 영역(합집합)만큼 잘라 새 프로젝트를 만듭니다. 콤마 구조, 레이어 시작 위치, 불투명도·블렌딩 모드는 그대로 옮기고 원본 프로젝트는 건드리지 않습니다. 새 프로젝트는 저장되지 않은 상태로 열립니다.

**불필요 프레임 삭제**: 완전히 투명한 빈 프레임과 연속된 같은 그림(콤마, 복사본 모두)을 지우고 전부 1콤마로 만듭니다. `A A - - B B B - C C → A B C`. Ctrl+Z 한 번으로 되돌릴 수 있습니다. 흰 배경처럼 불투명한 프레임은 빈 프레임으로 보지 않습니다.

## 1단계: EXE 만들기 (한 번만, 한 사람만)

**방법 A — GitHub (권장, PC에 아무것도 설치 안 함)**: 이 폴더를 GitHub 저장소에 올리면 Actions가 자동으로 테스트 후 EXE를 빌드합니다. 저장소의 Actions 탭 → 최근 실행 → Artifacts에서 `TVPaintAutoTools`를 받으면 됩니다.

**방법 B — Windows PC에서 직접**: Python 3.11을 설치한 PC에서 `build_windows.bat`을 더블클릭합니다. `dist\TVPaintAutoTools.exe`가 생깁니다.

플러그인 DLL(`tvpaint-rpc 1.1.0, TVP11용`)은 빌드할 때 자동으로 받아 EXE 안에 넣습니다.

완성된 EXE는 팀원들에게 파일로 나눠주면 됩니다. 코드를 고칠 때만 다시 빌드합니다.

## 2단계: 사용자 설치 (각 PC에서 최초 1회)

1. 1단계에서 만든 `TVPaintAutoTools.exe`를 원하는 곳에 둡니다. Python 설치는 필요 없습니다.
2. TVPaint를 켜고 EXE를 실행합니다.
3. "TVPaint에 연결되지 않음"이 뜨면 **플러그인 설치**를 누릅니다. 관리자 권한 창이 뜨면 허용합니다.
4. TVPaint를 완전히 껐다 켠 뒤 **다시 연결**을 누릅니다. 이후로는 EXE만 실행하면 됩니다.

Windows가 "알 수 없는 게시자" 경고를 띄우면 "추가 정보 → 실행"을 누르세요. 서명되지 않은 EXE라서 나오는 경고입니다.

## 3단계: 실기 QA 체크리스트

순서대로 확인하고, 실패한 항목 번호와 오류 창 내용을 알려 주세요.

1. 플러그인 설치 후 TVPaint 재시작 → EXE에 "TVPaint 연결됨"(초록 점) 표시. **Standard 에디션이면 이 단계가 가장 먼저 확인할 부분입니다.**
2. TVPaint에서 레이어를 바꾸면 1~2초 안에 EXE의 레이어 이름이 바뀜
3. 버튼을 누르면 확인창에 현재 레이어 이름이 뜨고, 취소하면 아무 일도 없음
4. 불필요 프레임 삭제: `A(2콤마) A복사본 빈칸 빈칸 B(3콤마) 빈칸 C(2콤마)` 레이어 → 결과 `A B C` 각 1콤마
5. 4번 직후 Ctrl+Z **한 번**으로 원래 상태 완전 복구 (가장 중요)
6. 레이어 시작이 1프레임이 아닌 경우(예: 25프레임부터)도 4번과 같게 동작
7. 불투명도 50% 레이어, 블렌딩 모드가 Color가 아닌 레이어에서 실행 후 원래 설정 유지
8. 다른 레이어의 표시/숨김 상태가 실행 전후 동일
9. Crop: 결과 프로젝트 크기가 그림 영역과 일치, 그림이 잘리지 않음, 콤마 구조 동일
10. Crop 후 원본 프로젝트에 변화 없음
11. 레이어가 잠겨 있거나 애니메이션 레이어가 아니면 안내 메시지 후 중단
12. 실행 도중 TVPaint를 끄면 "연결 끊김" 안내 (EXE가 멈추지 않음)
13. 인스턴스 300개 이상 레이어에서 소요 시간 기록

## 알려진 동작

불필요 프레임 삭제는 TVPaint의 잘라내기 기능을 써서 이미지 클립보드 내용을 덮어씁니다. 같은 그림 판정은 픽셀이 완전히 같을 때만입니다(1픽셀이라도 다르면 다른 그림). `A - A`처럼 빈 프레임을 사이에 둔 같은 그림은 하나로 합쳐지고, `A B A`는 셋 다 남습니다. 대상 레이어만 줄어들기 때문에 같은 클립의 다른 레이어와는 타이밍이 어긋납니다(시퀀스 리소스 용도 전제).

## 구성

`tvp_autotools/core.py`(픽셀 판정·계획, TVPaint 무관) / `ops.py`(작업 흐름) / `backend_tvp.py`(TVPaint 호출) / `ui.py` / `installer.py`. `tests/`의 테스트는 TVPaint 없이 가짜 백엔드로 로직을 검증합니다.
